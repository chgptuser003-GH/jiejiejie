# 原版功能與版面對齊原則

目標是重建使用者提供的原版插件功能和畫面，不增加新的店鋪業務功能。原版功能的名稱、入口、欄位、預設值、範圍、執行條件、結果及任務紀錄均要逐項對照；有欄位但未接通 API 不算完成。

CF 使用 Shopee Open Platform App。原版的 Seller Center 內部 API、Cookie 與原作者帳密服務不能直接沿用；店鋪 OAuth、本機配對和確認／回查屬於必要的接入與保護流程，應放在連線設定或原版操作的核對視窗，不另加到工具卡片或主表單。

## 目前已修正的額外入口

- 彈窗移除額外的商品／廣告測試查詢和快速利潤計算；利潤計算仍由原版的「利潤計算器 Pro」卡片進入。
- 廣告頁移除直接顯示在主表單下方的活動、績效、商品、篩選、健康檢查及單件測試面板。指定商品建立與批量 ROI／預算的核對流程改由原版按鈕開啟視窗。
- 批量刪除頁移除額外的預覽與 CSV 按鈕；原版操作按鈕目前只會開啟只讀核對視窗，不會送出刪除請求。
- 移除廣告頁的「API 對接進度」卡片、功能狀態徽章及側欄開發說明。

## 仍未與原版一致

- 原版各模組使用不同控制台頁面；CF 目前共用控制台與模組切換。各頁面仍須以原版 HTML/CSS 和截圖逐項驗收，不能宣稱逐像素一致。
- 彈窗仍需 CF 的店鋪連線設定；原版帳密授權已改為店鋪 OAuth。多站點切換尚未完成。
- 部分原版按鈕尚未接通 Open Platform 對應能力；系統 ROI、手動 ROI、加速推廣和廣告群組的等價性仍須核對。平台自動競價不等於已證明的原版系統 ROI。
- 預算水位線、商品、物流、行銷及限時特賣等頁仍有只讀預覽或尚未完成的流程。沒有完成 API 寫入、回查與沙盒驗收前，不標記為同等功能。

後續每個功能應按「原版欄位與互動 → 官方 API 能力 → 沙盒讀取 → 預覽與回查 → 沙盒寫入驗收 → 視覺對照」順序完成，不以新增可見測試工具代替原版操作。
