# Shopee 插件功能重建

這個工作區保存一份使用者提供的舊版插件作靜態分析，並建立以 Shopee Open Platform 為資料來源的新實作。舊版原碼放在 `legacy-extension/`，由 `.gitignore` 排除，避免在清理原有授權服務與憑證處理前誤公開。

目前完成：

- [功能盤點與遷移矩陣](docs/feature-inventory.md)
- [對接架構與驗收標準](docs/integration-architecture.md)
- `open-platform/`：後端使用的 Shopee 請求簽名、GET/POST、店鋪授權 URL、交換與刷新 Token、加密保存及按店鋪自動刷新；已按官方文件加入商品列表、廣告活動列表／設定／每日與每小時績效、手動商品廣告和店鋪 GMV Max 適配器；另已移植利潤計算和預算水位線判定核心並編寫單元測試
- `extension/`：全新 Manifest V3 插件源碼；彈窗有控制台入口，控制台列出舊插件 23 項功能及逐項狀態；只連本機後端，不讀蝦皮登入 Cookie，也不保存 Partner Key
- `dist/extension/`：執行建置後產生的可載入插件目錄（不提交版本庫）

0.3.0 開發版的彈窗會即時核對本機配對碼與沙盒店鋪授權；控制台會讀取沙盒在架商品及廣告活動數量，活動列表支援類型、起始位置與每頁件數查詢。「打開賣家中心」會進入臺灣沙盒站。

0.4.0 開發版新增「指定商品開廣告」中的沙盒單件手動選品試建：先預覽商品 ID、預算、日期及可選 ROAS，再確認送出。後端只接受與目前沙盒 Shop ID 一致、且含明確確認標記的請求。2026-11-03 已用商品 `846071597` 成功建立沙盒活動 `151139`（每日預算 TWD 85），並讀回活動設定與每日／每小時績效；原版批量廣告功能仍未完成。

0.5.0 開發版讓活動列表顯示名稱、狀態、預算、商品 ID 與目標 ROAS；績效表加入 CPC。另加入沙盒單件手動選品廣告修改工具，先讀取並預覽活動設定，確認後才送出，後端會再次核對目前設定。活動 `151139` 的預算修改已實測 85 → 90 → 85，兩次均讀回確認；ROAS 修改和暫停／恢復尚未實測。

0.5.1 開發版已實測活動 `151139` 的暫停及恢復，最後狀態仍為 `ongoing`。蝦皮沙盒拒絕對 `auto` 競價活動直接修改目標 ROAS；插件和後端源碼已加入預先阻止與說明。讀回設定偶發失敗時，插件會清楚顯示「請求已送出、讀回未確認」，避免誤以為可直接重試。

0.6.0 開發版增加「批量篩選廣告」的只讀工具：每頁最多 100 個活動，按日期、活動狀態、商品 ID、點擊、CPC、花費和 ROAS 篩選，並將目前結果匯出 CSV。資料來自活動設定和每日績效 API；跨頁自動掃描及篩選後刪除尚未接入。

0.7.0 開發版增加「廣告健康檢查」的只讀工具：檢查單頁活動設定、關聯商品狀態與指定日期的曝光／點擊。商品清單未覆蓋的 ID 顯示「未確認」，不當作違規；目前沒有可用的官方違規原因欄位，因此不宣稱能判定蝦皮違規。

0.8.0 開發版新增最多 10 個指定活動的沙盒批量預算修改工具。執行前讀取並預覽每個活動設定；送出時逐個修改、逐個讀回，遇到 API 失敗或結果不明就停止。最近一次執行狀態保存在插件本地儲存空間，供重新核對；此批量介面尚未在 Chrome 中實測。

0.9.0 開發版在「全店開啟廣告」加入在架商品投放預覽：比對商品與已掃描活動的關聯商品 ID；若活動未掃完，只顯示「未確認」，不宣稱可投放。單件試建工具移除自動競價模式下無效的目標 ROAS 輸入。此預覽不檢查庫存或建立資格，也不會批量建立活動。

目前插件能在本地計算利潤和預覽預算規則，並在後端配置及沙盒授權完成後查詢商品、廣告活動及績效；單件建立、預算修改、暫停與恢復已接入並實測。控制台中「部分完成」和「待對接 API」不表示原插件的批量或定時操作已完成。2026-11-03 已用 CF 測試 App 授權沙盒 Shop ID `228006723`，商品列表回傳 1 件（商品 ID `846071597`），並建立單件沙盒廣告 `151139`；廣告活動列表、設定、績效、單件預算修改和暫停／恢復均已實測成功。批量預算介面及其他寫入動作尚未實測。App 處於測試階段；沒有在插件、源碼或文件中寫入 Partner Key、Access Token、Refresh Token。

執行測試：

```powershell
cd open-platform
node --test
node scripts/build-extension.js
```

本機後端需要環境變數 `SHOPEE_PARTNER_ID`、`SHOPEE_PARTNER_KEY`、`SHOPEE_SHOP_ID`、`SHOPEE_REDIRECT_URL`、`SHOPEE_VAULT_KEY_BASE64`，然後執行 `node bin/server.js`。它只綁定 `127.0.0.1:8787`，啟動時會產生插件配對碼。不要把 Partner Key 或 Token 寫進插件或提交到版本庫。詳細步驟見[本機沙盒使用說明](docs/local-sandbox.md)。

CF App 已通過商品列表、廣告活動列表／設定／績效的沙盒讀取，以及單件手動選品廣告建立、預算修改和暫停／恢復。`auto` 競價活動的目標 ROAS 修改遭沙盒拒絕；刪除、批量和其他 Ads 端點尚未驗證。後續逐項驗證商品、物流、行銷與廣告寫入功能，再建立批量任務與排程。
